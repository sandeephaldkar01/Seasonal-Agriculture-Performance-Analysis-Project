<p align="center">

---

## 🌱 Project Overview

This project analyzes agricultural performance across different seasons using data related to **crop yield, production, environmental conditions, economic outcomes, and resource usage**.

The analysis compares three major seasons:

🌧️ **Kharif**  
❄️ **Rabi**  
☀️ **Zaid**

---

## 🎯 Objectives

- 📌 Analyze the number of agricultural records across seasons.
- 🌾 Compare crop yield and production.
- 🌦️ Study environmental conditions across seasons.
- 📈 Analyze yield variation.
- 🌱 Compare crop-wise yield.
- 💰 Analyze cost, revenue, and profit.
- 💧 Study resource usage and water efficiency.

## 🔍 Analysis Performed

### 1️⃣ 📊 Records Across Seasons
Comparison of the number of agricultural records available for:

- 🌧️ Kharif
- ❄️ Rabi
- ☀️ Zaid

### 2️⃣ 🌾 Agricultural Performance
Analysis of:

- Yield (Tonnes/Ha)
- Production (Tonnes)

### 3️⃣ 🌦️ Environmental Conditions
Analysis of:

- 🌧️ Rainfall
- 🌡️ Average Temperature
- 💦 Humidity
- ☀️ Sunlight Hours
- 🧪 Soil pH
- 💧 Soil Moisture

### 4️⃣ 📈 Yield Variation
The distribution and variation of agricultural yield across different seasons are analyzed using visualization.

### 5️⃣ 🌱 Crop-wise Yield
Yield comparison is performed for different crops across seasons.

### 6️⃣ 💰 Economic Outcomes
Analysis of:

- 💵 Market Price
- 💸 Total Cost
- 💰 Revenue
- 📈 Profit

### 7️⃣ 💧 Resource Usage
Comparison of:

- 🧪 Fertilizer Usage
- 🧴 Pesticide Usage
- 💧 Water Used
- ♻️ Water Efficiency
